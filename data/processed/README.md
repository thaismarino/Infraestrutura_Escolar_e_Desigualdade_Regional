# Camada Processed

Esta pasta representa a camada de dados processados do projeto.

Arquivo presente nesta camada:

`microdados_ed_basica_2024_filtrado.csv`

O arquivo foi gerado a partir do microdado original do INEP, mantendo apenas as variáveis necessárias à modelagem analítica e às consultas OLAP desenvolvidas na Etapa 2.

Essa etapa reduz dimensionalidade, melhora desempenho e garante foco nas variáveis estruturais relevantes.

Além do arquivo CSV filtrado, esta camada contém o dicionário de dados correspondente, documentando tipo conceitual, domínio de valores e descrição analítica das variáveis selecionadas.
